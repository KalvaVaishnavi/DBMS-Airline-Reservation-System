# Airline Reservation System – DBMS Course End Project

## Project Overview

This project is developed as part of the Database Management System Laboratory course at Vardhaman College of Engineering.

The project demonstrates database design and implementation for an Airline Reservation and Management System using Oracle SQL and PL/SQL.

## Project Contents

- `main.tex` – LaTeX source file for the project report.
- `main.pdf` – Compiled CEP report for quick preview.
- `logo.png` – Vardhaman College logo used on the report cover page.
- `sql/` – SQL and PL/SQL scripts numbered 01 to 11.
- `ER-Diagram` – Entity-Relationship diagram of the database.

## Technologies Used

- Oracle SQL
- PL/SQL
- Oracle SQL*Plus
- LaTeX
- Overleaf

## How to Compile the Report

Using a LaTeX environment, run the following commands:

```bash
pdflatex main.tex
pdflatex main.tex
```

Run the command twice to update the table of contents and references.

Alternatively, upload the complete LaTeX project ZIP to Overleaf and set `main.tex` as the main document.

Ensure that `logo.png` and all other required supporting files are present in their expected locations.

## How to Execute the SQL Scripts

1. Open Oracle SQL*Plus and connect to your Oracle database.
2. Execute the SQL and PL/SQL scripts in numerical order, from 01 to 11.
3. Refer to the project report for database design, queries, and implementation details.

Scripts 01–08 are also included in the report.
